Politique de confidentialité — AZ POS

Dernière mise à jour : septembre 2026

1. Qui sommes-nous

AZ POS est une application de point de vente pour commerçants (stock, ventes, clients, caisse). L’éditeur peut être contacté via le canal fourni sur la fiche Play Store / le site.

2. Données stockées

Les données commerciales (produits, clients, commandes, dépenses) sont enregistrées sur l’appareil (navigateur / application). Elles ne sont pas vendues à des tiers.

3. Caméra & micro

La caméra sert uniquement au scan de codes-barres / QR, si vous l’autorisez. Aucune vidéo n’est envoyée à un serveur pour cette fonction.

4. Notifications

Les alertes (stock bas, échéances) restent locales sur l’appareil si vous les activez.

5. Synchronisation équipe (optionnelle)

Si vous activez le mode multi-poste / livreurs, des données de tournées peuvent être synchronisées via le cloud configuré dans l’app, avec le code société et le secret que vous choisissez.

6. Vos droits

Vous pouvez exporter / effacer les données locales (vider le stockage du navigateur ou désinstaller l’app). Pour une demande liée au compte Play, contactez l’éditeur.

7. Contact

Utilisez l’adresse e-mail indiquée sur la fiche Google Play de AZ POS.
