# Guide d’utilisation — AZ POS v1.0

Application mobile pour commerces et grossistes en Algérie.

## Offre commerciale

- **Essai gratuit :** 14 jours
- **Licence :** annuelle (clé `GDZ1.…`)
- **Installation :** ajouter à l’écran d’accueil du téléphone

## Installation

1. Ouvrir le lien de l’app (Chrome Android / Safari iPhone)
2. **Ajouter à l’écran d’accueil**
3. Lancer AZ POS

## Fonctions principales

| Écran | Utilité |
|--------|---------|
| Accueil | Stats, alertes stock, dernières commandes |
| Commande | Vente + ticket + WhatsApp + facture |
| Agent | Commandes texte / voix (FR, arabe, darja) |
| Clients | Fiches + import contacts / collage WhatsApp |
| Reçues | Enregistrer une commande reçue sur WhatsApp |
| Stock | Produits, unités, quantités |
| Réglages | Nom commerce, langue, alertes, imprimante BT |

## Unités disponibles

pièce · carton · kg · g · m · cm · ml · L

## Agent — exemples

- `stock bas` / `stock na9es`
- `valeur du stock`
- `crédits` / `chkoune yekhlas`
- `ajoute client Karim 0555…`
- `calcule zakat` / `7seb zakat`
- `envoie facture`
- `aide`

## Zakat

Calcul **annuel** à 2,5 % (stock ± crédits). Pas à chaque transaction.

## Licence

À la fin de l’essai, coller la clé fournie par le vendeur sur l’écran d’activation.

Le guide web est aussi disponible dans l’app : `/guide.html`
