Dessins / photos originaux AZ POS (pas de packs de marques).
Inclus dans le site, Android (`npm run android:sync`) et Windows.
Le commerçant peut remplacer chaque photo depuis Stock.

### Open Food Facts (Algérie) — pack versionné

`off/` contient un **petit pack** (~100 photos JPG + `index.json`) **inclus dans le dépôt**
et donc dans chaque build web / Android / Windows.

- Scan code-barres → nom + photo (local hors ligne, ou API OFF en ligne)
- Pour **étendre** jusqu’à ~500 photos **avant un build** (sans tout committer) :
  voir `off/README.md` et `npm run off:pack`
