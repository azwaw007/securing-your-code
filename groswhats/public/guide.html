Guide d’utilisation — Grossiste DZ

Version 1.0 — application pour commerces et grossistes en Algérie.

Essai : 14 jours gratuits
Ensuite : licence annuelle (clé fournie par le vendeur)

1. Installer sur le téléphone

  1. Ouvre le lien de l’application dans Chrome (Android) ou Safari (iPhone).
  2. Menu → Ajouter à l’écran d’accueil.
  3. Ouvre l’icône Grossiste DZ.

2. Premiers réglages

  1. Va dans ⚙️ Réglages.
  2. Indique le nom de ton commerce, téléphone, ville.
  3. Choisis la langue : Français ou العربية.
  4. Enregistre.

3. Produits (Stock)

  • Ajoute tes produits : nom, catégorie, unité (pièce, carton, kg, g, m, cm, ml, L), prix, stock.
  • Le stock baisse automatiquement à chaque vente.
  • Les alertes de rupture s’affichent sur l’accueil.

4. Clients

  • Ajoute un client (nom + WhatsApp).
  • Ou importe des contacts téléphone (Android Chrome).
  • Ou colle une liste : Nom,0555123456

5. Créer une commande

  1. Onglet Commande.
  2. Choisis le client, ajoute les quantités.
  3. Valide.
  4. Ensuite tu peux :
    • Imprimer le ticket
    • Envoyer sur WhatsApp
    • Envoyer la facture WhatsApp

6. Commandes reçues

Quand un client commande par WhatsApp, va dans Reçues, enregistre le message, puis crée la commande.

7. Nouveaux arrivages

Onglet accessible depuis l’accueil / actions : choisis les produits arrivés, envoie le message WhatsApp à tes clients.

8. Agent (texte + voix)

Onglet Agent — dis ce que tu veux :

  • stock bas / stock na9es
  • valeur du stock
  • ajoute client … / zid client …
  • calcule zakat / 7seb zakat
  • envoie facture / sift factoura

Micro 🎤 : Français / العربية / دارجة (meilleur sur Chrome Android).

9. Zakat

Calcul une fois par an (2,5 % sur stock + option crédits). Ce n’est pas à chaque vente.

10. Activer la licence

  1. Après l’essai, l’app demande une clé.
  2. Colle la clé reçue du vendeur (commence par GDZ1.).
  3. Appuie sur Activer.

Support

Contacte ton vendeur Grossiste DZ par WhatsApp pour licence, installation ou formation.
